# edge-dl-lab

边缘设备深度学习练手项目集，目标是把每个项目完整走通：
数据 → 训练 → 量化 → 边缘部署 → 接入 ROS 2 / Zenoh 系统。

## 项目列表
- [ ] 01 KWS：语音指令词分类（进行中）
- [ ] 02 Detection：轻量目标检测
- [ ] 03 E2E Nav：端到端视觉导航
- [ ] 04 Anomaly：时序异常检测

## 目录说明
- `common/`：跨项目复用的基础模块（音频/视觉/训练/部署）
- `projects/NN_xxx/`：每个练手项目独立目录
- `notebooks/`：探索性实验与可视化
- `docs/`：每个项目的流程记录
