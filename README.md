# edge-dl-lab

边缘设备深度学习练手项目集，目标是把每个项目完整走通：
数据 → 训练 → 量化 → 边缘部署 → 接入 ROS 2 / Zenoh 系统。

## 项目列表
- [x] 01 KWS：语音指令词分类（✅ 模型训练完成，指标达标，待量化与 ROS2 部署）
- [ ] 02 Detection：轻量目标检测
- [ ] 03 E2E Nav：端到端视觉导航
- [ ] 04 Anomaly：时序异常检测

## 目录说明
- `common/`：跨项目复用的基础模块（音频/视觉/训练/部署）
- `projects/NN_xxx/`：每个练手项目的独立代码目录
- `checkpoints/NN_xxx/`：存放训练生成的模型权重（`.pth`）与特征缓存（`.pt`）
- `notebooks/`：探索性实验与可视化
- `docs/`：每个项目的流程记录与踩坑指南

## 快速开始 (以 01-KWS 为例)
请进入 `projects/kws/` 查看详细说明。

## 版本与数据管理规范
- **代码入库**：各项目的 Python 脚本均放在 `projects/` 目录下。
- **模型入库**：小于 10MB 的轻量级模型权重（如 `best_wakeword.pth`）直接提交至 Git；大于 10MB 的权重请使用 Git LFS 或 Gitea Release。
- **数据隔离**：原始数据集（音频/图像）与预处理缓存文件（`*.pt`）严禁提交，已在 `.gitignore` 中过滤，由各自项目的脚本自动生成。
